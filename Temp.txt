Localization of Proper Nouns and Entities Rules
• Phone Numbers: Localized Vietnamese phone numbers only need to start with the digit 0.
• Arbitrary Localization & Strict Consistency: Proper nouns (names, addresses, and other specific entities) do not require literal or semantically accurate translations. You may localize them using arbitrary Vietnamese equivalents (e.g., mapping "Whitney" to "Quỳnh" or a US address to a Vietnamese address). However, this exact mapping MUST be kept strictly consistent across all data fields within the same JSON file.
• Handling People's Names (Format): * If the source sentence has a Full name (First name + Last name) -> Localize into a full Vietnamese name (Họ + Tên đệm + Tên). Example: Ishaan Harris -> Nguyễn Quốc Cường.
• firstName field -> Only input (Tên đệm + Tên) or (Tên).
• lastName field -> Only input (Họ).
